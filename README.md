## 🌟 Flagship Project: [WorkFlow OS](https://github.com/Sujalranjan/WorkFlow-OS)

> **Watches the routine work you do across apps, spots what you repeat, turns it into a workflow you approve, then runs it through real integrations (Gmail, CRM, Slack), with a dry run first.**

```text
 Observe ─► Discover ─► DNA ─► Interpret ─► Spec + Approval ─► Plan ─► Execute ─► Verify ─► Learn
 (agent +   (repeated   (what   (LLM, checked  (human in the     (exact   (Gmail /   (independent (reliability
  browser    sessions)   stays/  against DNA)   loop)             routing)  CRM /      re-checks)    profile)
  extension)             varies)                                            Slack)
```

| ⚡ Highlight | 🔍 How |
|---|---|
| **Observation layer** | Windows desktop agent + Chrome/Edge extension stream real user actions |
| **Deterministic classification** | URL and metadata rules map events to an **Action Catalog** with no LLM guessing |
| **LLM interpretation** | The LLM describes the workflow and a validator rejects output that drops or re-routes steps |
| **Safety first** | Risk levels, a human approval gate, dry runs and fail-closed execution |
| **Real executors** | Gmail API, CRM API and Slack API, each with an independent verifier |
